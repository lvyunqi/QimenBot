# QimenBot Admin Brand Spec

## Assets

- Primary product mark: `../../../logo.jpg`
- Usage: 32px application avatar and compact identity only
- Treatment: circular crop, neutral hairline border, no decorative glow

## Visual System

- Direction: Quartz Console
- Primary surfaces: `#f6f7f5`, `#ffffff`, `#191a17`
- Brand accent: `#7656d8`
- Status colors: `#1c9a72`, `#c58b20`, `#d95e4c`
- Typography: Manrope Variable, Microsoft YaHei fallback, JetBrains Mono Variable
- Spacing: 4px base grid
- Radius: 6px controls, 8px panels
- Motion: 140-240ms, `cubic-bezier(0.2, 0.8, 0.2, 1)`

The interface is an operational tool. Brand color is an accent, not a page background.
